# Login Protection

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_358304_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/358304.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

A Minecraft Mod which protects the player during login and dimension change/respawn teleport from any harm, until the loading screen is over.

## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.

> This mod is officially distributed only through CurseForge. Downloads from other websites may be outdated, modified, or unsafe.
